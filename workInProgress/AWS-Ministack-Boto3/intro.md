# AWS Boto3 with MiniStack and Jupyter Lab

Welcome to this interactive lab!

In this scenario, you will learn how to use the **AWS SDK for Python (boto3)** to interact with a local, AWS-compatible API provided by **MiniStack**. To make this interactive and easy to visualize, we will be using **Jupyter Lab** as our development environment.

### What you will learn:
- Setting up a Python virtual environment with Python 3.12.
- Configuring Jupyter Lab.
- Connecting `boto3` to a local API endpoint.
- Performing basic S3 operations (creating buckets, uploading files).

Let's get started!
