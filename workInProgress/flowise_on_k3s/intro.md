# Flowise on k3s

Welcome to this lab! In this scenario, you will learn how to deploy **Flowise**, a powerful drag-and-drop tool for building LLM apps, onto a k3s cluster.

### What you will learn:
- Installing and setting up k3s.
- Using Helm to deploy applications on k3s.
- Managing services and port-forwarding for application access.

Let's get started!
