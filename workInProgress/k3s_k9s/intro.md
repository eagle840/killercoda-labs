# Bare Skeleton Lab Template

This lab will guide you through setting up and using **K3s** (a lightweight Kubernetes distribution) alongside **K9s** (a powerful terminal-based UI for Kubernetes).

By the end of this lab, you will:
1. Install K3s and configure non-root access for `kubectl`.
2. Inspect the resource consumption of the running cluster to see how minimal K3s is.
3. Deploy a scalable multi-replica Nginx application.
4. Download and run K9s to monitor and navigate your cluster visually directly from the terminal.

Click **Start Scenario** to begin!
