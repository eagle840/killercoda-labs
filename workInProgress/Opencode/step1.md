# Step 1: Install OpenCode

In this step, we will install the OpenCode CLI, which is the foundational tool for our AI-assisted development workflow.

### 1. Install OpenCode

Execute the following command to install the OpenCode CLI:

```bash
curl -fsSL https://opencode.ai/install | bash
```{{exec}}

Once the installation is complete, ensure your shell environment is updated to recognize the new command:

```bash
source ~/.bashrc
```{{exec}}

You can verify the installation by checking the version:

```bash
opencode --version
```{{exec}}
