# Step 4: Plan Mode vs. Build Mode & Parallel Sessions

Learn how to safely architect your application using Plan Mode.

### 1. Switching Modes
By default, OpenCode is in **Build Mode**. To switch to **Plan Mode** for reviewing architectural changes:
Press `Shift + Tab`.

### 2. Parallel Workflows
* **New context**: To start a completely new, clean context, use:
  ```text
  /new
  ```{{copy}}
* **Switch sessions**: Use the `sessions` command to switch between parallel development workflows.
