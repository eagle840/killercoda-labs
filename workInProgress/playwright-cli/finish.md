# Done!

You've successfully driven a real browser from the command line with `playwright-cli`. You can now:

- Open pages, navigate, and re-target elements by snapshot **refs** or CSS/role **selectors**.
- `type`, `press`, `fill`, `check`, and `uncheck` to interact with web apps.
- Export `screenshot` and `pdf` artifacts.
- Run **named sessions** and `state-save` / `state-load` to persist cookies and localStorage.
- Inspect the page with `console`, `requests`, `eval`, and `run-code`, and record `trace` and `video` artifacts.

## Where to go next

- Read the full command reference: `playwright-cli --help`
- Official docs: [playwright-cli for coding agents](https://playwright.dev/docs/getting-started-cli)
- The project repo: [microsoft/playwright-cli](https://github.com/microsoft/playwright-cli)
- Compare with Playwright's **test runner**: `npx playwright test`, `codegen` — for CI/test-suite automation.
- Playwright's **MCP**: for long-running autonomous agent workflows.

Remember: automate third-party sites responsibly and never point automation at production systems you don't fully control.
