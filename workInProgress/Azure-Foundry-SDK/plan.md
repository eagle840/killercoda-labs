# Lab Plan: Getting Started with Azure Foundry SDK

## Objective
To provide an interactive, hands-on experience using the Azure Foundry SDK for Python, transitioning from basic SDK experimentation to building a standalone AI web application.

## Steps

### Step 1: Environment Setup
*   Create and activate a Python virtual environment.
*   Install the Azure Foundry SDK (`azure-ai-projects`) and necessary dependencies.
*   Set up necessary authentication/configuration variables.

### Step 2: Exploring Azure Foundry via Jupyter Lab
*   Launch Jupyter Lab.
*   Initialize the Azure Foundry client.
*   Perform basic operations (e.g., listing projects, connecting to a model, sending a test inference request).

### Step 3: Building a Standalone AI App with Streamlit
*   Create a simple Streamlit application.
*   Integrate the Azure Foundry SDK code from Step 2 into the Streamlit app.
*   Run and interact with the AI-powered UI locally.

### Step 4: Conclusion
*   Summary of key Azure Foundry concepts.
*   Discussion on scaling and deploying AI applications built with this pattern.
