# Getting Started with Azure Foundry SDK

Welcome to this interactive lab!

In this scenario, you will learn the basics of using the **Azure Foundry SDK for Python** (`azure-ai-projects`) to interact with your Azure AI projects. To make this interactive and easy to visualize, we will be using **Jupyter Lab** for SDK exploration, followed by building a standalone, AI-powered web application using **Streamlit**.

### What you will learn:
- Setting up a Python virtual environment.
- Initializing and using the `AIProjectClient`.
- Building a standalone AI UI with Streamlit.

Let's get started!
