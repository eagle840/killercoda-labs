# Hello World! Basic use of Weaviate

We'll be following the quickstart guide using a Jupyter Notebook.

## Setup JupyterLab

Install JupyterLab:

`pip install jupyterlab`{{exec}}

## Launch JupyterLab

Start JupyterLab:

`jupyter lab --ip=0.0.0.0 --port=8888 --allow-root --no-browser`{{exec}}

In the terminal or via the browser, open `quickstart.ipynb` to complete the lab.
